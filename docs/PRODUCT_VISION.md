# PRODUCT_VISION

## 1. 개요

`HyuckHan/AlgorithmLectureNotes`의 Beamer 강의자료를 기반으로, 학부 컴퓨터공학 학생이
강의 전·중·후에 쓰는 **웹 기반 알고리즘 교재**를 만든다. 슬라이드 뷰어가 아니라, 혼자 읽는
연속적 교재 + 실행 가능한 코드 + 원본과 일치하는 시각화를 제공한다.

웹북의 역할:
1. **온라인 교재** — 개념·알고리즘·정확성·복잡도를 연속된 글로.
2. **강의 보조** — 기존 발표 PDF·handout과 연결.
3. **실습 환경** — C/Java/Python 코드, 예제 입력, 실행 결과, 퀴즈.
4. **시각화** — 정렬·재귀·트리·그래프·문자열 매칭의 상태 변화(강의노트 TikZ에서 변환).

## 2. 현재 자산 (진실의 원천)

- Lecture 01–10 Beamer 소스 (`lecture-notes/lectureNN/`)
- 발표·handout PDF 빌드 체계
- 공통 매크로/테마 (`lecture-notes/common`, `lecture-notes/theme`)
- C/Java 예제 코드와 일부 테스트 (`lecture-notes/code/`)
- **강의별 content map** (`lecture-notes/docs/lectureNN_content_map.md`) — 원본 PPTX 대비 교정·재구성 기록

웹북은 이를 대체하지 않고 **다른 표현 계층**으로 제공한다.

## 3. 대상 독자

1차: 알고리즘 과목 수강 학부생(자료구조 이수, 증명·복잡도엔 미숙, C/Java 기본 이해).
2차: 강의 준비·복습이 필요한 교수자/조교, 재학습하는 전환 학습자.

## 4. 교육 목표

학생이 (a) 문제의 입출력·전제 명시, (b) 핵심 아이디어의 의사코드화, (c) 작은 입력 손 추적,
(d) invariant·귀납·교환논증으로 정확성 설명, (e) 조건·비용모델에 따른 복잡도 분석,
(f) 적용 조건과 실패 사례 구분, (g) 코드 실행·경계 테스트, (h) 알고리즘 비교를 할 수 있게 한다.

## 5. 제품 원칙

- **정확성 우선** — 화려함보다 수학적·알고리즘적 정확성. content map의 교정(indexing·복잡도·용어·API)을 웹에서도 유지.
- **설명과 실행의 연결** — 각 핵심 알고리즘: 문제 → 아이디어 → 의사코드 → 추적 → 정확성 → 복잡도 → 구현 → 실습.
- **점진적 공개** — 전 강의를 한 번에 하지 않는다. **L03(정렬)을 수직 슬라이스로 완성**해 파이프라인·품질기준을 검증한 뒤 확장. (L03을 파일럿으로 삼는 이유는 §MIGRATION 참조: 의사코드 12·TikZ 18·코드 3버전이 모두 등장해 파이프라인 전체를 검증한다.)
- **소스 단일 책임** — Beamer=발표 원천, qmd=웹 교재 원천, `code/`=코드 원천. 중복은 동기화 정책 명시.
- **접근성 기본값** — 키보드 탐색, 색 대비(AlgoOrange를 텍스트로 쓰지 않음), 그림 대체텍스트, 애니메이션 정지, 모바일 가독성.

## 6. 범위

**MVP**: 홈·목차, L03 전체, 장별 URL·좌측 내비, 수식·코드 하이라이트, 이전/다음, 검색, PDF/handout 링크, 기본 퀴즈·정답, 정적 배포·CI.

**1차 릴리스**: L01–10 전체, 핵심 시각화(SVG), 코드 다운로드·실행 예제, 용어 색인, 강의별 학습목표·요약·퀴즈, 접근성·성능 검증.

**초기 제외**: 사용자 계정, 성적/LMS, 서버측 코드 실행, 진도 추적, 생성형 AI 채팅, 완성 다국어. (콘텐츠·정적 사이트 안정화 후 별도 결정.)

## 7. 성공 기준

- **콘텐츠**: L03 핵심 개념·예제가 content map과 일치. 모든 의사코드·코드가 검증됨. 각 페이지에 학습목표·요약/체크포인트.
- **사용성**: 3클릭 이내 도달. 모바일·데스크톱에서 본문·수식·코드 가로 스크롤 없음(긴 코드는 블록 내부만). 현재 위치·흐름 명확.
- **품질**: 빌드·링크·콘텐츠 스키마 검사 CI 통과. Lighthouse Perf/A11y/BP/SEO 각 90+ 목표. 핵심 페이지 WCAG 2.2 AA 심각 위반 0.
- **유지보수**: 새 페이지를 기존 템플릿으로 추가 가능. 콘텐츠 변경이 빌드 설정 수정 없이 가능. LaTeX 빌드와 웹 빌드 독립.
