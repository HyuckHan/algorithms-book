# DECISIONS — Architecture Decision Records

경량 ADR. 각 결정의 맥락·선택·근거·대안을 기록한다.

## ADR-001 · 정적 사이트 생성기로 Quarto 채택 (Next.js/MDX 아님)
- **맥락**: 강의노트는 수식·의사코드·다이어그램·다언어 코드가 많은 기술 문서다.
- **결정**: **Quarto book**을 쓴다.
- **근거**: 코드 실행 결과 삽입·panel-tabset(다언어)·수식·교차참조·HTML+PDF 동시출력이 1급 기능이고,
  프론트엔드 유지보수 부담이 낮다. 이미 LaTeX 툴체인에 익숙한 팀에 셋업 부담이 장벽이 아니다.
- **대안(기각)**: Next.js+MDX+React 시각화 — 웹 앱 개발 프로젝트가 되어 유지보수 부담이 크고,
  아래 ADR-003의 시각화 재구현 위험을 동반.
- **비고**: 인터랙티브가 핵심 가치로 판명되면 선별적으로 웹 컴포넌트를 얹는다(정적 우선).

## ADR-002 · 분리 저장소 + git submodule
- **맥락**: 산출물 저장소를 독립적으로 두고 싶다(사용자 결정).
- **결정**: `algorithms-book`을 신규 저장소로 만들고 강의노트를 `lecture-notes/` submodule로 포함.
- **근거**: 산출물 독립성 + 원본과의 재현성·추적성 유지. 강의노트 갱신은 submodule 포인터로 따라감.
- **대안(기각)**: 모노리포(`web/`) — 결합도가 높아 사용자 선호와 불일치.

## ADR-003 · 다이어그램은 TikZ→SVG 자동변환 우선 (React 재구현 아님)
- **맥락**: 강의노트에 검증된 TikZ가 **211개**(L06만 55개) 있다.
- **결정**: standalone LaTeX 컴파일 → **dvisvgm → SVG**로 자동 추출(해시 캐시). `\only` 오버레이는
  최종상태 평탄화 또는 학습상 중요한 것만 단계 SVG 시퀀스.
- **근거**: 원본과 픽셀 일치, 손 재작업 제거, "손으로 다시 타이핑하지 않는다" 원칙 준수.
- **대안(기각)**: 11종 React 시각화 컴포넌트 재구현 — 막대한 작업량과 원본 불일치 위험.
- **비고**: 인터랙티브 조작 학습이 핵심으로 판명되는 특정 그림만 선별적으로 위젯화(파일럿 이후).

## ADR-004 · 코드 3버전(C/Java/Python) 탭 + 파일 주입 + 실행 검증
- **맥락**: 사용자 요구. 강의노트에 Java·C는 있으나 Python은 없음.
- **결정**: `panel-tabset` + `include=`로 파일 주입. Python 신규 작성. CI에서 3언어 컴파일·실행,
  예제 stdout 일치 검증.
- **근거**: 출력 위조 방지, 원본 코드와 웹 표시 불일치 방지.

## ADR-005 · 의사코드는 pseudocode.js 자동변환 (손 타이핑 금지)
- **맥락**: 프로토타입에서 의사코드를 손으로 HTML에 넣어 줄바꿈·들여쓰기가 깨짐.
- **결정**: 소스 `algorithmic` 블록을 pseudocode.js 스니펫으로 자동 변환. 실패 블록만 SVG 폴백.
- **근거**: 재현성·정확성. 애셋은 vendoring(네트워크 비의존).

## ADR-006 · 콘텐츠 status 워크플로 도입
- **맥락**: 다인/장기 작업에서 검증되지 않은 콘텐츠가 공개되는 위험.
- **결정**: frontmatter `status`(draft→review→verified→published). 검증 증거 없이 상향 금지.
- **근거**: 거버넌스. content map 교정 보존을 검토 단계에 강제.

## ADR-007 · 수식은 MathJax 기본, MathML 프리렌더 허용
- **맥락**: 네트워크·폰트 의존 시 렌더 실패 위험(프로토타입에서 확인).
- **결정**: Quarto 기본 MathJax. 필요 시 KaTeX로 빌드시 **MathML 프리렌더**(네트워크 비의존).
- **근거**: "화면에 원시 수식 노출 0" 품질 게이트를 안정적으로 만족.
